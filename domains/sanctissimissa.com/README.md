A separate static introduction to the newer SanctissiMissa product, whose source is rebots-online/sanctissimissa (currently v1.66.30030). The running development preview is https://sanctissimissa.surge.sh — the host must be lowercase for Surge routing.

Upload the contents of this directory to the SanctissiMissa.com document root. This page does not change DNS, connect hosting, or publish an app build.

Preview images originate in the source project's store-assets/v1.16.34594 and are explicitly labeled earlier development previews because they retain the predecessor's branding. The current icon comes from public/icon.png. No claim is made that the newer product is the existing mba.robin.helloword production app.
